# ПР7. Ответы на контрольные вопросы

## 1. Что копируется при передаче параметра по значению?
Для int копируется само число. Для объекта класса копируется ссылка на объект. Поэтому можно изменить его поля, но нельзя заменить исходный объект.
## 2. В чём разница между ref и out?
ref требует, чтобы переменная уже имела значение до вызова метода. out не требует этого, но метод обязательно должен записать в неё значение.
## 3. Почему в int.TryParse используется out?
Потому что метод сам записывает результат преобразования в переменную. Ей не нужно иметь значение заранее.
## 4. Для чего нужен in?
in передаёт данные только для чтения. Он особенно полезен для больших структур, чтобы не копировать все их поля.
## 5. Где должны находиться необязательные параметры?
После всех обязательных параметров.
## 6. Для чего нужны именованные аргументы?
Они позволяют указывать значения по имени параметра, менять порядок аргументов и пропускать необязательные параметры.
